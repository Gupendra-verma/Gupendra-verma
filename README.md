**Product Comparison REST API** — A Spring Boot backend for comparing products across categories, specifications, prices, and reviews.

- 🔐 JWT-based authentication with **role-based authorization**
- ⚡ **Redis caching** with TTL-based expiration for frequently accessed APIs
- 🗄️ **PostgreSQL** with Spring Data JPA and Hibernate
- 🔎 Product comparison with **filtered search and pagination**
- 🧩 **20+ REST APIs** across authentication, products, reviews, specifications, and comparison
- 📖 API documentation with **Swagger/OpenAPI**
